# Changelog

## 0.1.0 — 2026-10-15

- Learn destination folders from labeled filenames using a local classifier.
- Generate JSON plans with supporting tokens and skipped-file explanations.
- Apply reviewed moves without overwriting destination files.
- Restore complete or interrupted runs from durable local journals.
- Check source hashes and Unix file identities, reject symlinks, and serialize commands with kernel file locks.
- Include a self-contained demo, integration tests, and a CI workflow.
